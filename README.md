# Connect

Connect is the online platform of the WailSalutem Foundation, where young people from Amstelland, organisations and the foundation find each other. Team 9 (Connect Nine) builds it as an HvA Social Impact Apps project.

- Documents: start at [docs/README.md](docs/README.md). What Connect must do is in [docs/project/requirements.md](docs/project/requirements.md).
- Branch flow: make a branch `<type>/<issue number>-<short name>` from `dev`, merge it back into `dev`, and `main` only takes merge requests from `dev`.
- Propose a change: push your branch, open a merge request into `dev` that starts with `Relates to #<issue number>`, and ask a teammate who did not write it to approve it.
- New in the team: [docs/team/onboarding.md](docs/team/onboarding.md). Rules for code, commits and reviews: [docs/team/codeConventions.md](docs/team/codeConventions.md).
- Run all of Connect on your own computer with one command: [part 13 of the getting started guide](docs/team/onboarding.md#13-run-all-of-connect-with-one-command).
